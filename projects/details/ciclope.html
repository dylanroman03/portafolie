Ciclope - OCR AI-Powered App

on production
Flutter Dart SQLite Node.js Javascript IA

Ciclope OCR is an AI-driven mobile application built with Flutter, integrated with Optical Character Recognition (OCR) technology to streamline invoice processing. The app allows users to capture or select invoice images (purchase or sale) from their device’s camera or gallery, extract relevant data, and populate an editable form. Users can verify and modify the extracted information before saving it locally on the app and synchronizing it with ADN Software’s enterprise system. This solution eliminates manual invoice entry, enabling accountants and businesses to process invoices efficiently by simply taking photos, verifying data, and syncing.


Key Features:

  • Invoice Scanning: Capture or upload invoice images, with support for batch scanning of multiple invoices.
  • OCR Data Extraction: Automatically extracts key invoice details to populate editable forms.
  • Local Storage and Sync: Saves invoices locally and synchronizes data with ADN Software’s system.
  • Multi-Account Support: Allows multiple user accounts for seamless access across teams.
  • Editable Forms: Users can review and edit extracted data before saving or syncing.

The project comprises two components: the Flutter-based mobile app for user interaction and a Node.js backend that processes images and performs OCR to extract information. Ciclope OCR enhances operational efficiency for businesses by automating invoice management, reducing errors, and improving workflow scalability.
