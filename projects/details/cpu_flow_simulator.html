CPU Flow Simulator is an interactive CPU scheduling simulator built with Flutter and Dart. The idea started in my Operating Systems course, where scheduling exercises had to be solved manually, so I built a visual tool that shows the same process step by step. It lets you define processes with arrival and CPU burst times, run different scheduling algorithms, and visualize the execution timeline alongside key performance metrics.


Supported Algorithms:

  • FIFO: First In, First Out.
  • SJF: Shortest Job First, non-preemptive.
  • Round Robin: with configurable quantum.

Key Features:

  • Process table: define arrival time and CPU burst time per process.
  • Execution queue: visualizes every time unit and which process is running.
  • Metrics: total time, average waiting time and average turnaround time.
  • Animations: optional animated run for a clearer visualization.
  • Bilingual UI: available in Spanish and English.

The project uses a feature-based architecture (domain and presentation layers) and is open source under the MIT License.
